# Handover packages

Self-contained source packages, each with everything needed to run, rebuild and verify the
thing it covers.

| package | what it is |
|---|---|
| [`cpolar_front_page/`](cpolar_front_page/) | the C-POLAR front page - the 3D mountain hero, the scroll story, the stylesheet, and the scripts that check a change did not break it |

## Downloading

Either clone the repository:

```
git clone https://github.com/aldrinor/nf-bigidea-preview.git
cd nf-bigidea-preview/handover/cpolar_front_page
```

or download the whole repository as a zip from the green **Code** button on
https://github.com/aldrinor/nf-bigidea-preview and take the `handover/` folder out of it.

A zip of this package alone is also attached to the latest release:
https://github.com/aldrinor/nf-bigidea-preview/releases
