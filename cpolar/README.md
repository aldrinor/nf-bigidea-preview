# C-POLAR front page — live demo

This folder is a **built copy for demonstration only**. It holds only the files
the browser actually fetches — 53 files, about 14MB.

**The source of truth is elsewhere:** the private repo `nanoflashing-website`,
branch `cpolar-front-page`, folder `front-page/`. That is where the tests, the
grading script, the design tokens, the lock files and the documentation live.
Do not edit anything here; edit there and redeploy.

The page carries `noindex, nofollow` so it will not appear in search results.
Anyone with the link can open it.

**It contains reference-site assets** — a 3D mountain, a compiled WebGL engine,
textures and fonts that are not ours. Those have to be replaced before this can
be treated as a real public site rather than a demo link shared with colleagues.
